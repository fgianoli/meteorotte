# Messaggi vocali

La schermata «Qui, adesso» (`qui.html`) fa comparire il tasto 🔊 solo se trova qui i file registrati.

Un file per pericolo e per lingua: `audio/<lingua>/<pericolo>.mp3`

- lingue: `it en fr ar fa ps ur ti wo mnk ff`
- pericoli: `flood rain cold heat snow wind none`

Il testo da leggere è quello di `web/js/i18n.js` (oggetto `MSG`). Vanno registrati da madrelingua, che così validano anche la traduzione.
